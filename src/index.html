Usage
Workflow:
  1. Import: Start by importing the artwork data from a URL that includes a query string encoding.
  2. Custom: Modify your artwork freely using the options available under each category tab.
  3. Export: Save your final artwork as either a PNG (raster) or SVG (vector) image format.
Tips:
The difference made by Path mode option (in Line tab)
  • Relative and merged: 'stroke-opacity' affects the whole lines group.
  • Absolute and separated: 'stroke-opacity' affects the appearance of each line.
Maximum rendering size for Width pixel size option (in Render tab)
The slider allows you to set the size up to 512 pixels, but you can type in a larger number manually into the box.
(Note: Larger sizes will exponentially increase the rendering time)
