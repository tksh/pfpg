Usage
Basic flow:
  1. Import artwork data from a URL containing a query string.
  2. Modify your artwork freely using the options in each category tab.
  3. Export your artwork as a PNG (raster) or SVG (vector) format via export buttons.
Configuration options:
Tab Sections:
  • The Lines, Canvas, Render tabs offer settings to customize the artwork's appearance.
  • The UI tab allows you to adjust the website's behavior.
Modal Dialogs:
  • Click/tap the reset icon (restart_alt) to reset settings by category.
  • Click/tap the rendered PNG image to access the sharing feature.
  • Click/tap the source SVG input field to access optimization settings.
Additional Information:
Effect of the Path mode option (in Lines tab):
  • Relative and merged: 'stroke-opacity' applies to entire line groups.
  • Absolute and separated: 'stroke-opacity' applies to individual lines
Maximum rendering size for Height pixel size option (in Render tab):
The slider supports sizes up to 512 pixels, but you can manually enter a larger value into the box.
(Note: Larger sizes will exponentially increase rendering time)
