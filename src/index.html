Tips for customization
The difference made by Path mode
- Relative and merged: 'stroke-opacity' affects the whole strokes group
- Absolute and separated: 'stroke-opacity' affects the appearance of each stroke
Maximum rendering size for Width and height
The slider allows you to set the size up to 512 pixels, but you can type in a larger number manually into the box.
(Note: Larger sizes will exponentially increase the rendering time)
