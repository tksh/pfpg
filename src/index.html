Color and two opacities for line groups:

id: stroke, opacity, stroke-opacity

Artwork format:
Color randomization:

0 keeps each color's original value; a larger value widens its random range. Hue has no effect on gray, whose chroma is zero, so raise Chroma range as well to change a gray's color.

Each randomize click redraws every line group's Lightness, Chroma, and Hue offsets within the ranges set above. Uniform: every amount within each range is equally likely, so a color can move anywhere in the range. Triangular: offsets cluster near zero and thin out toward the range edges, so most lines barely change and large shifts are rare.

Original line colors draws every group from the colors the artwork defines, ignoring any color override in the link, so repeated clicks give variations of the same palette; Current line colors draws from the colors the link currently carries, so each click builds on the last and repeated clicks drift away from the original.

Relative and merged: 'stroke-opacity' applies to entire line groups. Absolute and separated: 'stroke-opacity' applies to individual lines.

The slider supports sizes up to 512 pixels, but you can manually enter a larger value into the box. Larger sizes will exponentially increase rendering time.

Usage
Basic flow:
  1. Import artwork data from a URL containing a query string.
  2. Modify your artwork freely using the options in each category tab.
  3. Export your artwork as a PNG (raster) or SVG (vector) format via export buttons.
Configuration options:
Tab Sections:
  • The Lines, Canvas, Render tabs offer settings to customize the artwork's appearance.
  • The UI tab allows you to adjust the website's behavior.
Modal Dialogs:
  • Click/tap the reset icon (restart_alt) to reset settings by category.
  • Click/tap the rendered PNG image to access image optimization settings.
  • Click/tap the source SVG input field to access optimization settings.
Shortcut Keys:
  • Press A, S, D, or F to switch between the Lines, Canvas, Render, and UI tabs, respectively.
  • Press R to open the reset settings dialog.
  • Press E to randomize colors.
