Third-party licenses

pfpg itself is distributed under the Mozilla Public License 2.0. This page reproduces the license texts of the third-party software this site ships whose licenses require the text to travel with the software: the WebAssembly rasterizer with everything compiled into it, the image encoders with the codecs compiled into their modules, and the bundled colorjs.io color conversion. Each entry here corresponds to a credit in the About section of the main page, where the libraries are listed with what contains what.

  • svg2ui8a-MIT.txt svg2ui8a — the SVG rasterizer's JavaScript, bundled into the page.
  • resvg-LICENSE-MIT.txt resvg — the Rust SVG rendering library compiled into the rasterizer's WebAssembly module. Distributed under the MIT license.
  • resvg-LICENSE-MIT.txt usvg — the SVG parser resvg builds on, compiled into the rasterizer's WebAssembly module. Distributed under the MIT license; its text is the same file as resvg's, listed above, because both crates carry an identical notice.
  • roxmltree-LICENSE-MIT.txt roxmltree — the XML parser usvg uses, compiled into the rasterizer's WebAssembly module. Distributed under the MIT license.
  • tiny-skia-LICENSE-BSD-3-Clause.txt tiny-skia — the 2D rasterizer resvg draws with, compiled into the rasterizer's WebAssembly module.
  • svgtypes-LICENSE-MIT.txt svgtypes — the SVG data types shared by resvg and usvg, compiled into the rasterizer's WebAssembly module. Distributed under the MIT license.
  • colorjs-MIT.txt colorjs.io — the color-space conversion (sRGB ↔ OKLCH) and CSS Color 4 gamut mapping, bundled into the page. Distributed under the MIT license.
  • jsquash-webp-Apache-2.0.txt @jsquash/webp — the WebP encoder's JavaScript, bundled into the page.
  • jsquash-webp-codec-libwebp-BSD-3-Clause.md libwebp — the WebP codec, compiled into the WebP encoder's WebAssembly module.
  • jsquash-oxipng-Apache-2.0.txt @jsquash/oxipng — the PNG optimizer's JavaScript, bundled into the page.
  • jsquash-oxipng-codec-oxipng-MIT.md oxipng — the PNG optimizer, compiled into the PNG optimizer's WebAssembly module.
