# pfpg

Profile picture generator

## With Deno std/http file server

<https://docs.deno.com/runtime/tutorials/file_server>

```sh
# Install
deno install --allow-net --allow-read https://deno.land/std/http/file_server.ts
# Run
file_server .
```
